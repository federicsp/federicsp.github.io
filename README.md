# federicsp.github.io

Personal link-in-bio website for Federico Spatola, built with
[HugoBlox](https://hugoblox.com/) and deployed to GitHub Pages.

## Local development

Requirements: Hugo Extended, Go, Node.js 22, and pnpm.

```bash
pnpm install
pnpm dev
```

The production site is built and deployed automatically from `main` by the
GitHub Actions workflows in `.github/workflows/`.
